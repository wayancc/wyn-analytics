# Contributing

Thanks for helping. Bug reports, ideas and pull requests are welcome.

## Before you open a pull request

1. **Sign the CLA.** The CLA Assistant bot asks you to sign when you open your first pull request. It lets the project keep its dual license (AGPL app, MIT tracking script) and offer the code under other terms later. You keep the copyright to your work.
2. **Run the tests:** `php tests/run.php`. They need no dependencies and no internet.
3. **Keep it small and dependency-free.** No Composer packages, no build step, and nothing that loads from a CDN or another server.
4. **Follow the WYN naming.** `wyn-` for CSS classes, data attributes, asset files and headers; `wyn_` for tables; `Wyn…` for PHP namespaces and JS globals.
5. **Privacy first.** Nothing may store an IP address, a raw user agent or a cross-day identifier. If a change touches tracking, add a test for it.

## Reporting a security problem

Please don't open a public issue. Email the maintainer through [wayan.cc](https://wayan.cc) instead.
